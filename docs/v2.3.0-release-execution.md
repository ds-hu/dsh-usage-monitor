# v2.3.0 发布执行记录

本轮发布自 `fork-v2.2.0`（`aac1f5d`）以来的两批改动：**统计图折线可读性**与**统计图悬停读数**
（同一提交 `8059e4f`）。前者是修 2.2.0 的缺陷（折线看着像画断了、圆点被拉成椭圆），后者是新增的
读数交互，因此递增次版本号到 **2.3.0** 而不是补丁号。

语义化依据：新增的是统计图上的读数交互，无破坏性变更；`usage.json` 与 `quota.json` 的格式、
`/state` 与 `/settings` 的契约都没有变化，2.2.0 的宿主与 2.3.0 的客户端仍可按原方式互通。

## 1. 变更范围

| 能力 | 实现位置 | 说明 |
| --- | --- | --- |
| 采样锚点 | `lib/client.js` `UsageChart` 的 `.qm-chart-overlay` | 每个变化点一枚圆点；叠加层不带 `viewBox`（位置用百分比、半径用像素），不随 `preserveAspectRatio="none"` 拉伸 |
| 换窗口虚线 | 同上 `.qm-chart-drop` | 两段之间用同色虚线接上；实线仍在窗口边界断开，不跨窗口连线 |
| 悬停读数 | `lib/client.js` `quotaUsedAt` / `clockOf` / `UsageChart` | 指针位置 → 时刻 → 该时刻之前最近一次采样（保持到下一次变化，不插值）；浮层给时刻、当日 Token 与各窗口剩余百分比 |
| 吸附与键盘 | 同上 `snap` / `onPointerMove` / `onKeyDown` / `onPointerLeave` | 8px 内吸附到实际采样时刻；←/→ 在时间轴上走，失焦收起；触屏点按固定读数 |
