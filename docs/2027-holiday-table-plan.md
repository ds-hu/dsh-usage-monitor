# 2027 年节假日表补录方案

日期：2026-11-07。状态：**已执行（数据与测试）**，未发布、未提交。执行与验证结果见 §10。

基线：HEAD `46187a1`（工作树干净），`npm test` **155 passed / 0 failed**。

## 1. 为什么现在动

ADR-0001 把「每年 11 月国办发布次年安排后补 `lib/season.js` 的 `HOLIDAY_VALLEY`」定成唯一年度维护动作。
现表只有 2026（33 天）。缺次年**不会报错**，只会把工作日假期静默按峰价计费（多算钱）；今天起
`/state` 与启动日志已经在报「节假日表缺少 2027 年的安排…（已覆盖：2026）」。

敞口量化（用当前 `lib/season.js` + 下方候选日期实测，把候选表当作覆盖表参数传入，没改一个字节）：

| 口径 | 数字 |
| --- | --- |
| 2027 放假日 | 29 天 |
| 其中落在**工作日**（今天会被判成峰价） | **18 天** |
| 会按峰价多算的高峰小时 | 18 × 7 = **126 小时**（09–12、14–18） |

这 18 天：元旦 1/1（周五）；春节 2/5、2/8–2/12；清明 4/5；劳动 5/3–5/5；端午 6/9；中秋 9/15；
国庆 10/1、10/4–10/7。补录后它们全部 `kind = holiday`、全天谷价。

## 4. 会先红的既有断言

| 位置 | 现在钉住的事实 | 补录后 |
| --- | --- | --- |
| `test/season.mjs:105–114` | 「2026 视点缺 2027」，注释写着「正是当前真实状态」 | 2026 视点 warning 变 **null** → 必须改写 |
| `test/runtime.mjs:123–126` | 精确字符串「…（已覆盖：2026）」、warning 含 `2027`、启动日志含 `2027` | 真实日期 2026-11 下 warning 变 **null** → 必须改写 |

改法：

- `season.mjs` 的用例改为三段注入式判定（`coverageWarning` 已接受 `at` 参数，不引入时间炸弹）：
  2026 视点 → `null`；**2027 视点 → 点名「2028」且不提「缺少 2026/2027」**；覆盖表非空 → `null`。
- `runtime.mjs` 改负断言：`first.season.warning` 不得点名 2026 或 2027（真实日期下应为 `null`），
  启动日志同理；缺年文案的精确文本由 `season.mjs` 的注入式用例负责。

新增断言（把这次的数据钉死，防止补录时打错一天）：

- 2027 的键集合与上表 29 项逐项相等（不是计数相等）；
- 春节 2/9 10:00 → `peak = false`、`kind = holiday`、`valleyReason = holiday`；
- 元旦 1/1（周五）10:00 → holiday（这是「工作日假期」的典型样本）；
- 中秋 9/15 单日 → holiday，9/16 10:00 回峰；
- 调休 10/9（周六）→ 仍 `kind = weekend`，不因「上班」变峰价；
- 春节期间的 `nextFlip` = 2027-02-15 09:00（节后首个工作日），且不为 `null`。

## 6. 验证步骤

1. `npm test` —— 基线 155/0，改造后应为 155 ± 改写的项数，全绿。
2. **反向验证（AGENTS §7）**：先备份 `lib/season.js`，把「2027-02-13」改成「2027-02-12」再跑测试，
   新断言必须红；`git checkout`/字节还原后用 sha256 比对备份，确认逐字节一致。
3. `node --check lib/season.js`（纯表改动，语法风险接近零，仍跑一次）。
4. 不改代码即可复核数据的办法（候选表当覆盖表传入，规则与内置表同一份代码）：

```powershell
$code = @'
import { isPeak, dayKind, nextFlip } from "./lib/season.js";
const days = ["2027-01-01" /* …29 项… */];
for (const d of days) {
  const at = new Date(d + "T10:00:00+08:00");
  if (isPeak(at, days) || dayKind(at, days) !== "holiday") console.log("✗", d);
}
console.log("nextFlip 春节中 →", new Date(nextFlip(new Date("2027-02-09T10:00:00+08:00"), days) + 8 * 3600_000).toISOString());
'@
$code | node --input-type=module
```

  本轮已跑过一次：29 天全部识别为 holiday，补录前其中 18 天报峰价，春节中 `nextFlip` = 2027-02-15 09:00。
5. 真实宿主（人工）：`lib/` 变更要**重启 DSH 宿主**（不是 HMR）→ `/state` 的 `warning` 变 `null`，
   设置页覆盖表旁不再点名；启动日志不再留缺年记录。
6. `npm run test:pack`：打包文件数不应变化（没有新文件进包）。
