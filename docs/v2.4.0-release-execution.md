# v2.4.0 发布执行记录

本轮发布自 `fork-v2.3.0` 之后的三个提交：单一面板重构（`525bc0f`）、明细面板的对齐与
图表标注修复（`1376ba4`）与重构记录文档（`5ce458a`）。

语义化依据：这是界面架构调整——四个浮层、八个视图收敛为一个面板——按 `docs/releasing.md` 的约定
递增次版本号到 **2.4.0**，而不是补丁号。`usage.json`（版本 2）与 `quota.json`（版本 1）的格式、
`/state` 与 `/settings` 的契约都没有变化，2.3.0 的宿主与 2.4.0 的客户端仍可按原方式互通。

可见行为上的减法：用量浮卡、供应商限额明细弹窗与用量统计弹窗不再存在，侧栏卡片单击直接打开
「用量监控」面板，面板只剩「概览」「供应商」两个页签。这一条在发布说明里点名，不藏在「重构」里。

## 1. 变更范围

| 能力 | 实现位置 | 说明 |
| --- | --- | --- |
| 单一 surface 状态机 | `lib/client.js` `createMonitorSurface` | `host`（dialog/page/null）+ `tab` + `editing` 取代原先 `popover/detail/stats/dialog/page` 五个互斥布尔 |
| 面板宿主 | `lib/client.js` `PanelHost` | dialog（遮罩 + 焦点陷阱）与 page（宿主设置内嵌）两个 adapter 共用面板内容；关闭后焦点回到侧栏卡片 |
| 供应商行 | `lib/client.js` `metricRowsOf` / `MetricTable` | 额度／余额／报告三组与表格列语义集中在一处，概览与编辑页预览复用；一次只展开一行 |
| 额度历史按需取 | 展开首个供应商时请求一次 `/state?quota=1` | 同一面板会话内复用，不再为统计弹窗单独请求 |
| 文案预算 | `test/copy.mjs` | 中英同键同占位符、已删除文案不得回流、词典 ≤160 键（实测 158，重构前 198 个唯一键） |
| CSS 注入完整性 | `test/css.mjs` | 顶层不得出现无选择器声明；清理旧浮层规则时留下的换行声明会吞掉后续基础样式 |
| 样式热替换 | `lib/client.js` `ensureStyle` | 复用同一个 `<style data-plugin-css>` 并每次重写内容，不再因标签已存在而直接返回 |

设计与取舍（含被否决的替代方案）见 [ADR-0002](adr/0002-single-monitor-surface.md)，过程与视觉证据见
[单一面板重构执行记录](single-panel-refactor-execution.md)。

守卫非空洞：`test/css.mjs` 的「顶层不得出现无选择器声明」正是本轮清理事故的回归用例——只删选择器、
留下换行后的声明时，CSS 解析会把它们当作下一条规则的选择器，静默吞掉 `.qm-overlay`、`.qm-pill`、
`.qm-watch`、`.qm-chart` 的基础规则（详见重构记录）。`test/copy.mjs` 同时守住「已删除文案不得回流」
与 160 键上限。本轮没有另做注入实验。

- 未接真实 DSH、未访问真实计费账户：浏览器套件用替身供应商与预置夹具，截图来自 Playwright 测试壳，

  Chromium 用例与真实 React 渲染器断言。
- 深色/浅色主题下的对比度未逐一取色验证，面板沿用现有 surface/border token。

  进入同一面板。数据格式与宿主契约未变，回退到 2.3.0 不会损坏已写入的 `usage.json`／`quota.json`。
